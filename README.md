## 📦 Installation & Setup
Run the turnkey bootstrap script:
```bash
chmod +x setup.sh
./setup.sh
```

## 🛠 Usage
Launch the sovereign dashboard:
```bash
python3 main.py
```
Or use the CLI for direct commands:
```bash
python3 main.py --cli --goal "Automate my daily research and draft an email"
```
